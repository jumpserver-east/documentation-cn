# Product introduction

## 1 What is JumpServer?
!!! tip ""
    JumpServer is a popular open source bastion host and a professional operations security audit system that complies with 4A specifications. JumpServer helps enterprises control and log in all types of assets in a more secure manner, achieve prior authorization, in-process supervision, and post-event auditing, and meet the compliance requirements of Class A guarantees.

![index_02](https://www.jumpserver.com/images/jumpserver-arch-light.png)

!!! tip ""
    The asset types supported by JumpServer bastion host include:

    - SSH (Linux / Unix / network equipment, etc.)
    - Windows (Web connection / native RDP connection)
    - Database (MySQL / MariaDB / Oracle / SQLServer / PostgreSQL / ClickHouse, etc.)
    - NoSQL (Redis / MongoDB, etc.)
    - GPT (ChatGPT, etc.)
    - Cloud services (Kubernetes / VMware vSphere, etc.)
    - Web site (Web management backend for various systems)
    - Applications (connect various applications through Remote App)

## 2 product features
!!! tip ""
    JumpServer product features include:

    - Open source: zero threshold, quick acquisition and installation online;
    - Distributed: easily supports large-scale concurrent access;
    - No plug-ins: only a browser is required for the ultimate Web Terminal experience;
    - Multi-cloud support: One system manages assets on different clouds at the same time;
    - Cloud storage: audit recordings are stored in the cloud and will never be lost;
    - Multi-tenancy: one system used by multiple subsidiaries and departments at the same time;
    - Multi-application support: database, Windows remote applications, Kubernetes.
