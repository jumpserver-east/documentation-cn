# Prologue

## Overview

Thank you for choosing JumpServer. This manual describes how to operate and maintain the JumpServer bastion host (hereinafter referred to as "JumpServer" or "the system").

The content in this manual provides general guidance and is not guaranteed to cover every use case for every product model. The information in the manual may differ from the interface displayed on your device because of version upgrades, device models, or project-specific configuration. In such cases, use the information displayed by your device. These differences are not described individually in this manual.

IP addresses, URLs, domain names, and similar values may appear in feature descriptions and configuration examples. Unless otherwise stated, these values are examples only and do not refer to actual systems.

## Intended Audience

This document is intended for system administrators who operate and maintain JumpServer. Readers are expected to understand:

- Basic network communication protocols such as TCP/IP and HTTP.
- Basic principles, configuration, and operation of common systems and devices such as databases, servers, routers, and switches.
- Basic Docker container concepts.
