## 2 Component Description
!!! tip ""
    - The Core component is the core component of JumpServer, and other components depend on this component to start.
    - Koko is a component that serves Unix-like asset platforms and provides character connections through SSH and Telnet protocols.
    - Lion is a component that serves the Windows asset platform and is used to access Windows assets on the Web.
    - XRDP is a component that serves the RDP protocol. The main function of this component is to access the assets of Windows 2000, XP and other systems through JumpServer Client.
    - Razor is a component that serves the RDP protocol. JumpServer Client uses Razor components by default to access Windows assets.
    - Magnus is a component that serves the database and is used to access database assets through a client proxy.
    - Kael is a component that serves the GPT asset platform and is used to manage ChatGPT assets.
    - Chen is a component that serves the database and is used to access database assets through a Web GUI.
    - Celery is a component that handles asynchronous tasks and is used to perform JumpServer-related automation tasks.
    - Video is specially designed to handle the format conversion of videos generated by Razor components and Lion components, and convert the generated session videos into MP4 format.
    - Panda is an application publishing machine based on domestic operating systems and is used to schedule Virtualapp applications.
