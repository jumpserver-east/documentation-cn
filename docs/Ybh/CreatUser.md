# 创建用户

<!-- 步骤1：带数学符号的导航说明 -->
1. 在页面左上角，选择![图2](图2.png "可选标题")符号，然后点击![控制台](控制台.png "可选标题"){: width="125" height="80"}。

![图1](图1.png "可选标题"){: width="400" height="300"}

2. 进入 **用户列表** 页面...

2. 进入 **用户列表** 页面，点击 + **创建** 按钮。

3. 在 **姓名** 字段中输入用户全名。

4. 在 **用户名** 字段中输入 JumpServer 登录账号（需唯一）。

5. 在 **邮箱** 字段中输入电子邮箱（需唯一）。

6. （可选）在 **用户组** 字段中选择一个或多个用户组。

7. 在 **密码设置** 字段中选择密码配置方式：

<!-- 表格（描述密码设置选项） -->
| 选项                          | 说明                                                                 |
|-------------------------------|----------------------------------------------------------------------|
| **生成重置链接并发送给用户**  | 提交表单后，用户将收到邮件，通过邮件中的链接自行设置密码。           |
| **直接设置密码**              | 用户可使用该密码直接登录。<br>若勾选"下次登录时必须修改密码"，用户首次登录后需强制修改密码。 |



<ol start="8">
  <li>在 <strong>MFA</strong> 字段中，选择以下选项之一。</li>
</ol>


| 选项                          | 描述                                                                 |
|-------------------------------|----------------------------------------------------------------------|
| **禁用**                      | 默认禁用MFA，但用户可以选择启用它。                                   |
| **启用**                      | 默认启用MFA，但用户可以选择禁用它。                                   |
| **强制启用**                  | 强制启用MFA，用户无法禁用它。                                         |


<ol start="9">
  <li>在 <strong>来源（Source）</strong> 字段中，设置用户来源。对于手动创建的用户，建议选择“本地（Local）”。</li>
  <li>在 <strong>系统角色（System roles）</strong> 字段中，选择一个或多个系统角色。</li>
  <li>在 <strong>组织角色（Organizational roles）</strong> 字段中，选择一个或多个组织角色。</li>
  <li>在 <strong>启用（Active）</strong> 字段中，勾选以启用用户（默认）。取消勾选将禁用用户并阻止登录。</li>
  <li>在 <strong>过期日期（Date expired）</strong> 字段中，设置用户的过期时间。过期后，用户将无法登录。</li>
  <li>（可选）在 <strong>电话（Phone）</strong> 字段中，输入电话号码。</li>
  <li>（可选）在 <strong>描述（Description）</strong> 字段中，提供用户的附加信息。</li>
  <li>点击 <strong>提交（Submit）</strong> 或 <strong>保存并继续（Save & Continue）</strong>。</li>
</ol>
