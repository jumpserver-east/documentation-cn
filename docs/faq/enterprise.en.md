# Enterprise Edition

## 1 What is the difference between JumpServer open source version and enterprise version?
!!! tip ""
    **JumpServer's core functions are all open source, new versions are released on a monthly basis, and it is free to use forever. **

    Compared with the JumpServer open source version, the JumpServer Enterprise Edition provides X-Pack enhancement packages for enterprise-level application scenarios, as well as high-level original enterprise-level support services. It also provides JumpServer operations security best practices, effectively helping enterprises quickly build and operate their own operations security audit systems.

    X-Pack enhancements include some additional features required by enterprise-level customers, such as page customization of logos, multi-organization management, support for management of Oracle, PostgreSQL databases, etc.; the specific features of the X-Pack enhancement package will continue to increase with the release of new versions;

!!! tip ""
    - [JumpServer Enterprise Edition Feature List](https://www.jumpserver.org/enterprise.html)

!!! info "X-Pack enhancement package functions will continue to be added on a monthly basis following the JumpServer version iteration. Enterprise version customers can use the new functions without paying additional fees during the service period."
