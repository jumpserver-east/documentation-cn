# Preface

## Overview

Thank you for choosing JumpServer bastion host. This manual describes in detail some common API usage methods of the JumpServer bastion host (hereinafter referred to as "JumpServer" or "system").

The X-JMS-ORG parameter in the API request header of this document refers to the organization management function of the enterprise version. If left blank, it defaults to the Default organization.

Due to version upgrades or different project configuration files, etc., the API content provided in the manual may be inconsistent with what users use. Please refer to the API information in the current version of the online Swagger UI. The differences caused by the above situations will not be explained one by one in the manual.

For the purpose of function introduction and configuration examples, IP addresses, URLs, domain names, etc. may be used in the manual. Unless otherwise specified, the above contents are for illustration only and do not imply any actual meaning.

## Intended readers

This document is mainly applicable to developers who use JumpServer, including system docking, secondary developers, etc. Readers should have the following basic knowledge:

- Basic usage of REST API
- Programming language basics (such as Python, Bash, etc.)
- Basic usage methods and core product concepts of the bastion host system
